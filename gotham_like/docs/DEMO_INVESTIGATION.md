# Demonstration investigation

> Everything referenced here is **SYNTHETIC / DEMONSTRATION DATA** generated by
> `scripts/generate_synthetic.py` (seed 42). No real people, organisations, accounts or
> places are represented. Findings below are *analytical signals* and *hypotheses*, not
> conclusions.

## The ten steps

Run `python scripts/demo_investigation.py` (server running) or
`python scripts/demo_investigation.py --in-process`. The script performs the steps through the
public API and writes [`examples/DEMO_TRANSCRIPT.md`](examples/DEMO_TRANSCRIPT.md), the report
([`md`](examples/investigation_report.md), [`pdf`](examples/investigation_report.pdf),
[`json`](examples/investigation_report.json)) and exports (CSV, GraphML, GeoJSON, JSON).

In the UI (`http://localhost:5173`, user `investigator`):

1. **Search** — `Ctrl+K`, type `device:DV-7F3A-SHARED`, Enter.
2. **Open entity profile** — right panel shows properties, relationship counts, signals; *Profile* tab lists every relationship with pagination.
3. **Expand graph** — *Expand 1-hop* (or double-click the node). Parallel observations collapse into `USED ×5` style edges.
4. **Filter relationships** — *Filters* tab: keep `USED`, set the time window to March 2026; hide Location types; raise minimum confidence.
5. **Open timeline** — *Timeline* tab: stacked histogram + per-type lanes; zoom and *Apply as time filter*; simultaneous-event groups are flagged.
6. **Open map** — *Map* tab: *Fit to data*, *Heatmap*, *Radius query* (click near Harbor Plaza with 2000 m), trajectory of the selected entity.
7. **Inspect provenance** — click an edge: *Why does this relationship exist?* shows source, source record, ingestion time, transformation version, confidence and analyst modifications; *Cite* pins the source record.
8. **Create hypothesis** — *Investigation* tab → create investigation → *Pin workspace entities* → shift-click subjects → *Create hypothesis* (stored as ANALYST ASSERTION — HYPOTHESIS).
9. **Save investigation** — every change is persisted (versioned, audited, broadcast to collaborators); the *Query* tab can *Save query* into the investigation.
10. **Export report** — *Report PDF / MD* and *Export…* (CSV/JSON/GraphML/GeoJSON).

The end-to-end browser test (`frontend/tests/e2e/smoke.mjs`) automates this flow in Chromium
and stores screenshots in `docs/screenshots/`.
